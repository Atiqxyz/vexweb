# VEX website

The official VEX landing page, built as a lightweight static website.

## Preview locally

From this directory, run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current footer year

The site is intentionally dependency-free. It has not been deployed from this repository.
