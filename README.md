# VEX — Official Website

The official landing page for the VEX programming language project.

## Local preview

This is a dependency-free static website. Open `index.html` in a browser, or serve the directory with any static file server:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000.

## Structure

- `index.html` — semantic page structure and content
- `styles.css` — visual system, responsive layouts, and motion
- `script.js` — mobile navigation and scroll reveals

## Content accuracy

Current implementation details are based on the VEX compiler repository's README and working specification. Planned capabilities are explicitly presented as future directions.
