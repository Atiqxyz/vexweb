01 / INTRODUCTION

A LANGUAGE BUILT WITH A BIGGER AMBITION.

Small beginnings.
Wide horizons.

VEX is an ongoing effort to develop a capable, general-purpose low-level programming language. The project is being developed incrementally, with its compiler, language features, and surrounding ecosystem evolving together.

The goal is to create a language that provides meaningful control without artificially restricting what developers can build with it.

02 / PHILOSOPHY
THE CENTRAL IDEA ↘

Low-level at its foundation.
Broad in what it can do.

V•X

VEX is not intended to be a high-level language disguised as a low-level one. Its identity is built around genuine low-level programming, while its long-term direction includes a broad collection of tools and capabilities. The objective is to make low-level control and extensive functionality coexist.

03 / CURRENT IMPLEMENTATION

A FOUNDATION TAKING SHAPE.

What exists
right now.

A selection of capabilities present in the current compiler. The implementation is deliberately early, and the supported language surface remains limited.

01

Static semantics

Primitive types, local type inference, type checking, and function signatures.

LANGUAGE
02

Functions & control flow

Function declarations, parameters, returns, conditionals, and repetition.

STRUCTURE
03

Core expressions

Integer and floating-point arithmetic, comparisons, boolean logic, and strings.

OPERATIONS
04

Intermediate representation

A typed SSA intermediate representation, with lowering and verification.

COMPILER
05

Native compilation paths

Initial C11 and LLVM IR backends, with a command-line compiler workflow.

BACKENDS
06

Mathematical intrinsics

Initial built-ins for square root, sine, cosine, power, and absolute value.

04 / FUTURE DIRECTION

STILL DEVELOPING. A LOT MORE TO BUILD.

The next chapters
are unwritten.

These are directions for future development, not features available in the current implementation.

A / 01

Closer to the machine

More extensive low-level capabilities, memory control, and pointer semantics.

A / 02

A wider foundation

Modules, imports, expanded error handling, and a comprehensive standard library.

A / 03

Beyond systems

Scientific and numerical computing, hashing, cryptography, filesystem, and networking.

A / 04

Visual computing

Long-term possibilities in graphics, visualization, animation, and game development.

A / 05

Building VEX with VEX

A long-term ambition is to make the language expressive enough to implement a substantial compiler in VEX itself: a step toward self-hosting readiness.
