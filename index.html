01INTRODUCTION

A language built
with a bigger ambition.

VEX is an ongoing effort to develop a capable, general-purpose low-level programming language. The project is being developed incrementally, with its compiler, language features, and surrounding ecosystem evolving together.

The goal is to create a language that provides meaningful control without artificially restricting what developers can build with it.

VEX / A LANGUAGE IN PROGRESS
02PHILOSOPHY

THE CENTRAL IDEA

Low-level at its foundation.
Broad in what it can do.

VEX is not intended to be a high-level language disguised as a low-level one. Its identity is built around genuine low-level programming, while its long-term direction includes a broad collection of tools and capabilities. The objective is to make low-level control and extensive functionality coexist.

04FUTURE DIRECTION

STILL DEVELOPING. A LOT MORE TO BUILD.

Where VEX is
heading.

These are ambitions for future development, not claims about features already available in the language.

A

Deeper low-level control

More extensive control over memory and pointers.

B

A broader language foundation

Modules and imports, expanded error handling, and a comprehensive standard library.

C

More capable libraries

Hashing and cryptography, alongside broader filesystem and networking capabilities.

D

Scientific & computational work

Scientific and numerical computing as part of the language's wider purpose.

E

Graphics & visual applications

Future possibilities include 2D and 3D graphics, animation, visualization, and game development.

F

Building VEX with VEX

Long-term self-hosting readiness, including the ability to implement a substantial compiler in VEX itself.

THESE ARE FUTURE DIRECTIONS, NOT IMPLEMENTED FEATURES.
