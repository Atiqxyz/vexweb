01 / INTRODUCTION

A LANGUAGE BUILT WITH A BIGGER AMBITION.

Designed with
ambition.

VEX is an independently developed, general-purpose low-level programming language. It is being built as its own language and compiler project, with its own direction and long-term ambitions.

The project is still young. Its language design, compiler, and ecosystem will continue to evolve as development progresses.

02 / PHILOSOPHY
THE CENTRAL IDEA ↘

Low-level by design.
General-purpose in vision.

V•X

VEX is being developed as a low-level language with a general-purpose ambition. The aim is not to limit the language to one narrow category of software, but to build a foundation that can grow into a wide range of uses.

03 / THE VISION

A LANGUAGE WITH ROOM TO GROW.

One foundation.
Many possibilities.

VEX is being developed with a long-term goal of supporting a broad range of programming tasks. That ambition is a direction for the project, not a claim that every capability exists today.

04 / FUTURE DIRECTION

STILL DEVELOPING. A LOT MORE TO BUILD.

The next chapters
are unwritten.

These are directions for future development, not features available in the current implementation.

A / 01

Closer to the machine

More extensive low-level capabilities, memory control, and pointer semantics.

A / 02

A wider foundation

Modules, imports, expanded error handling, and a comprehensive standard library.

A / 03

Beyond systems

Scientific and numerical computing, hashing, cryptography, filesystem, and networking.

A / 04

Visual computing

Long-term possibilities in graphics, visualization, animation, and game development.

A / 05

Building VEX with VEX

A long-term ambition is to make the language expressive enough to implement a substantial compiler in VEX itself: a step toward self-hosting readiness.
